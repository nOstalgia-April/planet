## 操作与经济

默认 P1 弧形地面近景；滚轮向下一格进入 P2 总览，向上一格返回。从 P2 切回 P1 时，以切换瞬间星球屏幕正上方（12 点钟方向）的地表方向作为主视角水平中央，在原有弧形地平线中央展开；使用自转或手动转动后的实际显示朝向，不返回进入总览前的旧方向。切换结束当前拖动，地平线高度、前景范围及真实巢穴／怪物坐标不变。P1 主视角在星球本体按住右键起拖，空白背景不起拖；P2 缩略视角在空白背景按住右键起拖，星球本体不起拖。两种视角的界面都不接收起拖。P2 缓慢自转，默认约 2°/秒；手动拖动时暂停，松开后继续。P1 不自转。

吸管悬停逐只处理中心附近的怪物；`1`／`2` 切换工具，捕网解锁后左键投网。P2 只供观察与转动，不能治理或捕捉；巢穴只生成在最外围边界线上，转到近景顶部后可直接治理。拖动、切换视图、离开目标时清除未完成的吸取和脱附；已经投出的网继续结算。捕网容量为 5／10／20／30，冷却 6 秒，工具栏实时显示剩余冷却或就绪。吸管共 7 档：每只 0.60／0.45／0.32／0.22／0.17／0.135／0.11 秒；基础速度不变，最高吞吐量为旧最高档两倍。吸管六次强化价为 10／30／70／120／180／260 糖果；捕网三次扩容价为 10／30／70，首次解锁另付 10。

吸管科技只强化处理速度。黏液怪只在中心被选中后推进脱附与吸入；中心以外保持正常活动。

鼠标悬停巢穴查看并购买治理；移入详情面板保持显示，离开后关闭。工具栏悬停出现解锁或快捷升级卡，其他科技在科技树购买。科技树弹窗阻止背景工具和镜头操作。

史莱姆值 2 糖果，黏液怪值 4 糖果。黏液怪留下连续贴地拖痕，暂定 7 秒消退、最长 72 世界单位、半宽 7。旧拖痕保持原地并随星球转动，吸走怪物后仍逐渐消退。

每巢投入 16／32／64 糖果，经历野生 → 培育 → 半治理 → 完全自动化。巢穴培育科技（20 糖果）开放第一阶段建设，完全自动化科技（100 糖果）开放其余建设阶段；科技树没有单独的半治理项。半治理设施每 1.15 秒尝试采集，黏液怪每三次尝试处理一次，金色个体需人工处理；完全自动化每 0.5 秒尝试，黏液怪每三次、金色个体每六次可优先处理。设施保留当前吸管目标和未落地个体。每次收入均对应真实实体采集，不使用后台固定产钱。

| --- | --- | --- |
| 吸管动力 | 全局 | 缩短单体处理时间 |
| 捕网 | 全局 | 先解锁，再扩容 |
| 巢穴治理 | 全局解锁 | 巢穴培育 → 完全自动化，逐巢建设 |

- `scenes/world/nest.tscn`、`governed_region.tscn`、`overview_ecology.tscn`：基础巢穴、近景真实物种地块，以及总览外沿统计和气泡。

## 音效协作

FMOD 导入与试听工具位于 `audio/fmod-import` 分支。

- [Fred / AI 交接入口](docs/audio/fmod_ai_handoff.md)：本次更新范围、Demo 体验、接口定位与验证边界。
- [FMOD 导入手册](docs/audio/fmod_import_guide.md)：准备事件、构建音频包并导入项目。
- [FMOD 测试通路手册](docs/audio/fmod_test_route.md)：独立试听、参数检查和问题反馈。
- 试听入口：在 Godot 打开 `features/fmod_audio_test/fmod_audio_test.tscn`，按 F6。

当前主玩法仍使用原有四个 WAV 音效。这个分支提供 FMOD 插件与独立试听通路，实际音频包由音效同事在 FMOD Studio 中制作。

已在 Notion [新增吸尘器两阶段音效需求](https://app.notion.com/p/3f0ab9cff760812fbad7cedb67273b90)并艾特 Fred：分别处理从黏液上拔出时的受阻持续声、拔出后的正常吸取声，以及阶段切换、中断和不同升级档位的时长。该项为待制作需求，本轮未替换主玩法音频。

## 2026-10-08 场景美术预览与主菜单

F5 从主菜单启动，点击 start 进入近景游玩预览；「预览」可选择近景、全景、吸尘器、捕网与黏液怪移动。五个预览均可单独打开按 F6 运行。本轮不导入星星/月亮与彩色恢复素材。入口、帧率、素材范围与验证见 [场景预览说明](features/场景预览/README.md)。
