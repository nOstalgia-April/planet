# 看板娘说话音效测试入口

2026-10-16 更新。使用 GitHub `main` 的完整项目和 Godot **4.7.2**。主菜单「预览」现在只保留下面三个入口。

## 最快开始

1. 更新项目后打开根目录 `project.godot`，等待首次资源导入完成；首次导入后关闭并重新打开一次编辑器。
2. 按 **F5**，进入主菜单后点「预览」，选择需要测试的阶段。也可以直接打开下表场景，按 **F6**。
3. 入场后会自动依次播放台词。用「重播」反复对照入场、说话和句间待机；「下一句」先补全正在显示的句子，再按一次进入下一句。

| 菜单入口 | 独立 F6 场景 | 播放范围 |
| --- | --- | --- |
| 1. 开头看板娘说话速通 | `res://features/mascot_audio_preview/opening_audio_preview.tscn` | 斗篷形态，完整 13 句：开场 8 句 → 上方小对白的吸尘器说明 1 句 → 捕捉反应 1 句 → 收尾 3 句 |
| 2. 第二阶段入场与说话 | `res://features/mascot_audio_preview/phase_two_audio_preview.tscn` | 肌肉形态入场，完整 10 句 |
| 3. 第三阶段入场与说话 | `res://features/mascot_audio_preview/phase_three_audio_preview.tscn` | 小史莱姆滑入，完整 8 句 |

开头「速通」会跳过片头影片、选工具、实际捕捉及等待奖励的操作门槛，按当前开头对白顺序自动串联；不加速说话。第二、第三阶段直接进入对应形态，不要求先玩到对应进度。三个入口共用近景背景，不模拟阶段二、三的整套生态变化。

| 操作 | 按钮 / 快捷键 |
| --- | --- |
| 从入场重新播放本入口 | 重播 / **R** |
| 补全当前句；已完整时进入下一句 | 下一句 / **空格、Enter** |
| 返回主菜单换阶段 | 返回 / **Esc** |

默认每秒 **15 字**；中文标点额外停 **0.22 秒**；整句显示完后待机 **2.2 秒**，再自动进入下一句。最后一句结束后隐藏气泡，角色持续待机，方便听停止和尾音。开头捕捉反应与收尾之间另有 **1.8 秒**待机，可按下一句跳过。

## 接自己的说话音效

**当前没有交付专属看板娘语音 Bank，三个场景的 `Talk Event Path` 默认留空。** 此时可以看动作和台词，但不会播放看板娘说话声。已有背景音乐在测试入口中停止，背景玩法也不推进；场景树和 FMOD 音频系统保持运行。

1. 在 FMOD Studio 中制作可以开始、停止的 **2D 说话循环事件**。事件名由音效老师决定，无须套用新的固定命名。按项目现有配置将事件分配到 `ProjectVacuum` Bank，并 Build Desktop。
2. 停止运行中的 Godot 场景，把同次 Build 的 `Master.bank`、`Master.strings.bank`、`ProjectVacuum.bank` 放到项目的 **`bank/Desktop/`**。这三个入口不读取旧独立试听目录 `assets/fmod/banks/`。
3. 在 Godot 打开要测的入口场景，选中最上层根节点，在检查器的 **Talk Event Path** 填入实际完整事件路径（以 `event:/` 开头），保存后按 F6。三个入口可分别配置不同事件。
4. 测完一个阶段后按 R 重播，再按 Esc 换入口。更新 Bank 后停止运行并重新启动，让新 Bank 重新加载；R 只重播，不重载 Bank。

事件会在开始逐字显示时启动，整句文字显示完时停止；入场、句间和最终待机不会继续触发说话循环。按下一句补全文字，也会立即请求停止声音。停止使用 FMOD 的允许淡出方式，尾音长度由事件自己的 release 决定；重播和离开场景也会停止并释放当前实例。

这条接口用于按说话动作启停的循环音效；长篇逐句录音还没有按录音时长驱动字幕，也没有逐句事件映射。若制作的是完整配音，请先把事件路径和句子对应表交给程序同事，再安排字幕时长接入。

若没有声音，先确认 `Talk Event Path` 不为空、实际事件已分配并构建到上述 Bank、游戏音效音量未静音，以及编辑器的音频静音开关已关闭。事件不存在时 Godot 输出会提示 `FMOD event missing`。不要把场景能播放等同于新声音已经接入。

## 动作和台词

第一阶段使用现有斗篷入场、待机和五帧说话动作。第二阶段使用现有肌肉入场、待机和六帧张嘴动作，张嘴动作 8 帧/秒。第三阶段目前没有独立张嘴原画：入场为 0.75 秒滑入，说话暂用原四帧起伏动作以 8 帧/秒播放，待机为 5 帧/秒。

第二阶段逐句内容：

1. 咦？这个巢穴怎么不再往外冒小家伙了？
2. 地上还亮起来了……这些颜色，是从巢穴里跑出来的？
3. 难怪看着眼熟。我们刚来的时候，这里好像就是这个颜色。
4. 等等，你清理巢穴，为什么连里面攒着的糖果也一起放走了？
5. 你又清完一片了……难怪我连喊话都没刚才有劲了。
6. 我看明白了。巢穴里的颜色回到地上，我们从这里得到的力量也在消失。
7. 你说的“治理生态”……原来管的还有我们啊？
8. 可我们也不是故意的！飞船坏了，大家又饿，看到这里有吃的才留下来。
9. 我以为，多存点糖、多照顾几个小家伙，总不会有错……
10. ……你先答应我，收进去的那些家伙，一个都不能少。

第三阶段逐句内容：

1. ……原来这颗星球，本来这么漂亮。
2. 刚落地的时候，我只顾着看哪里有糖了。
3. 现在没那么多力气了，倒是终于能坐下来，数清楚大家了。
4. 你已经上报星际督查局了？……他们会把我们怎么样？
5. 口头警告，还有救援教育？
6. ……原来飞船遇难，可以申请星际救援啊。
7. 好吧。下次先求救，不乱吃，也不随便挖窝了。
8. 那个……申请救援的时候，能不能顺便申请一顿饭？我们这次会按数量领的。

## 给程序同事

台词和节奏配置在三个入口场景及其 `MascotDialogue` 节点。开头的四段对白分别放在根节点的 `Intro Lines`、`Vacuum Lines`、`Reaction Lines`、`Closing Lines`。开头预览保留当前教程的四段对白与大小对白切换，后续改开场文案时需要同步这份速通台词。

共用对白脚本为 `scripts/ui/mascot_dialogue.gd`：`form_index` 选择 0/1/2 形态，`line_started(index, text)` 开始说话，`line_finished(index)` 完成一行，`dialogue_finished` 完成整段。开头分段时句子索引会从 0 重新开始。

三个入口共用 `stage_audio_preview.gd` 的循环音效连接；开头的大、小对白均接入同一个循环实例所有者。最终待机、重播和离开时没有遗留说话实例。此音效连接仅用于这三个测试入口，正式剧情触发与正式教程的音频暂停规则需另行接入。
