# FMOD 测试通路

本场景让音效同事直接确认 Bank 能否加载、事件能否播放、吸取参数是否有效，不需要先玩主游戏。当前主游戏仍使用 Godot 原生音效；本场景的试听结果不代表主玩法已经迁移到 FMOD。

仓库起始不含制作好的 Bank。可以先用“测试音频输出”检查 FMOD 是否能输出项目已有 WAV，再按 [FMOD 音效导入手册](fmod_import_guide.md) 生成音频包。在 Bank 到位前，缺文件提示是预期状态，Bank 事件播放、参数与设计听感暂不能确认。

## 1. 先看完整链路

```text
FMOD Studio 2.03.06
    ↓ 事件分配到 SFX，File → Build（Desktop）
Master.strings.bank + Master.bank + SFX.bank
    ↓ 三个文件一起复制
planet/assets/fmod/banks/
    ↓ Godot 4.7.2 打开当前分支
features/fmod_audio_test/fmod_audio_test.tscn → F6
    ↓ 加载 / 重新加载音频包
固定事件试听 + 任意事件路径试听
    ↓ 开始吸取，改变 Progress
停止全部 → 重启场景 → 再次验证
```

每一步都要通过。Studio 里能听见声音，只能确认源工程；需要 Build、复制和重新加载，Godot 才会使用新结果。

## 2. 打开独立试听场景

1. 确认项目处在 `audio/fmod-import` 分支，使用 Godot **4.7.2**。首次打开完整项目时，等待资源导入结束，关闭并重新打开项目一次，再进行下面的试听。
2. 在文件系统面板打开 `res://features/fmod_audio_test/fmod_audio_test.tscn`。
3. 按 **F6** 运行当前场景。F5 运行默认主游戏，不是这次的试听入口。
4. 检查界面上的 Bank 目录为 `res://assets/fmod/banks`。
5. 场景启动时自动尝试加载一次。点击“加载 / 重新加载音频包”，阅读状态区。缺文件、缺事件或缺参数时，先按下方定位表处理。

三个必需文件直接位于 `assets/fmod/banks/`，不是其 `Desktop/` 子目录：

```text
Master.strings.bank
Master.bank
SFX.bank
```

按路径查找事件依赖字符串 Bank，不能只复制 `SFX.bank`。[维护者 Bank 加载说明](https://fmod-gdextension.readthedocs.io/en/latest/user-guide/4-loading-banks/)

## 3. 不依赖 Bank 的输出预检

点击“测试音频输出”，应听见项目已有 `assets/audio/collect.wav` 的一声。这条通路使用 FMOD Core 直接播放 WAV，不需要先创建事件或生成 Bank；缺 Bank 时仍可使用。

状态会明确提示“仅验证 FMOD 输出，不代表 Bank 事件通过”。它适合先排查运行库、系统音量和输出设备。听到这一声后，仍要完成后面的 Bank 加载、事件与参数检查。没有 Bank 时，固定事件与任意事件的播放按钮会禁用，这是正常状态。

## 4. 固定收集事件

1. 点击“播放收集音”。
2. 应听见 `event:/Slime/Collect` 的完整一次声音，随后自然结束。
3. 间隔一会儿再点击一次，确认可以重复触发。
4. 如果使用的是导入手册中的 `collect.wav`，先确认声音与 Studio 中一致；这个素材用于通路验证，最终声音可以以后替换。

若状态显示事件未找到，回 Studio 检查 `Slime/Collect` 的大小写、Bank 分配和最近一次 Build，不需要先调整游戏代码。[维护者事件播放说明](https://fmod-gdextension.readthedocs.io/en/latest/user-guide/5-playing-events/)

## 5. 吸取循环和三档参数

1. 把 `Progress` 滑条放在 `0`，点击“开始吸取”。
2. 保持播放，先调到 `0.5`，再调到 `1`，停留几秒比较。
3. 缓慢从 `0` 拖到 `1`，再拖回 `0`，检查变化是否连续。
4. 点击“停止吸取”，确认循环退出；重新开始一次，确认可以再次播放。

三档预期需要与音效同事在 Studio 中设置的自动化对应。推荐的设计如下，并非程序替声音自动生成的效果：

| Progress | 推荐听感 | 检查重点 |
|---|---|---|
| `0.0` | 吸取开始，较轻的状态；可以保留可听见的底声 | 循环确实在播放，不必强制静音 |
| `0.5` | 中等强度、正在持续吸取 | 与 0 和 1 有可辨认的区别 |
| `1.0` | 接近完成、最紧张或最强的状态 | 无突然爆音、削波或过度音量 |

参数必须是事件内连续参数 **`Progress`**，范围 **0–1**，属于 `event:/Tools/Suction`。如果 Studio 中没有为参数配置自动化，Godot 滑条即使成功传值，也不会有听感变化。[Studio 参数说明](https://www.fmod.com/docs/2.03/studio/parameters.html)

请另外听循环接缝是否有咔哒声，来回拖动时是否突变，以及开始和停止是否符合预期。界面状态成功不能代替这些人工试听。

## 6. 测自己的新声音

1. 在 Studio 创建非空间的 **2D Timeline 事件**，例如 `Tests/MySound`，用自己的素材完成设计。此试听入口不支持含空间设置的 3D 事件。
2. 分配到 `SFX`，重新 Build Desktop 平台。
3. 在试听场景停止正在播放的事件，把同次 Build 的三个 Bank 一起替换到约定目录。
4. 点击“加载 / 重新加载音频包”。
5. 在任意事件路径区输入完整路径 `event:/Tests/MySound`，点击“播放事件”，再点击“停止事件”验证停止。

任意事件路径区用于检查这个事件能否播放和停止；固定 `Progress` 滑条用于吸取事件，不代表自定义事件的所有参数都已经有界面控制。测试完自己的事件后，再确认两个约定事件仍然存在。

## 7. 修改后重新加载与重启

每次修改声音、事件名、Bank 分配或参数后，按照同一个顺序更新：

1. 保存 Studio 工程并 **File → Build**。
2. 在 Godot 试听场景停止吸取和任意事件。
3. 覆盖 `Master.strings.bank`、`Master.bank`、`SFX.bank`，保持三个文件来自同一次 Build。
4. 点击“加载 / 重新加载音频包”，重新试听。
5. 停止场景，重新按 F6，再加载并试听一次，确认效果不依赖旧的运行状态。

若系统提示文件正在使用，先停止整个试听场景，再复制 Bank；复制完成后重新运行。若事件仍是旧声音，核对复制源是本次 Desktop 输出，必要时重启 Godot 编辑器。

## 8. 常见问题定位

| 现象或状态 | 先检查哪里 | 处理方法 |
|---|---|---|
| 缺 Bank 文件 | `assets/fmod/banks/` | 检查三个文件和大小写；从 Desktop 输出复制，去掉多余目录层级 |
| 缺 Bank、事件按钮不可用，但想先验证电脑输出 | “测试音频输出”按钮 | 先试听已有 WAV；它只验证 FMOD 输出，制作并加载 Bank 后再测事件 |
| Bank 加载失败或版本不兼容 | Studio 版本、Build 平台、文件完整性 | 使用 Studio 2.03.06，重新 Build Desktop，把三个文件一起替换 |
| 缺 `Collect` 或 `Suction` 事件 | Studio 事件路径与 Bank 分配 | 保留约定路径，Assign to Bank → SFX，重新 Build 和加载 |
| 有 Bank，但事件路径查找失败 | `Master.strings.bank` | 确认它与另外两个 Bank 是同次 Build；不要混用旧字符串 Bank |
| 缺 `Progress` 参数 | `Tools/Suction` 事件 | 添加事件内连续参数，名称完全一致，范围 0–1；重新 Build |
| 参数传值成功，声音没有变化 | Studio 参数自动化 | 给音调、滤波或素材混合等添加自动化，并先在 Studio 中比较三档 |
| 播放成功但听不见 | Studio 事件、电脑输出设备、音量 | 先在 Studio 确认素材和轨道没有静音；检查 Master/事件音量与系统输出；首次使用非空间 2D 事件 |
| 吸取只响一声便结束 | Studio 时间线循环设置 | 添加并检查循环区域，在 Studio 先确认能持续播放 |
| 更新后仍是旧声音 | Build 输出与复制时间、运行中旧实例 | 停止事件，重新复制和加载；重启场景，必要时重启编辑器 |
| 按 F5 进入游戏，没看到试听按钮 | Godot 当前运行入口 | 打开 `fmod_audio_test.tscn`，按 F6 |
| 首次导入出现 `Nonexistent function`，对象为 `FmodServer` | 插件首次导入状态 | 等待导入结束，关闭并重新打开项目一次；若重开后仍报错，保存完整错误文本交给开发同事 |
| 插件没有加载或报原生库缺失 | Godot 版本和完整项目文件 | 使用 4.7.2，重新取得完整分支；把报错文本交给开发同事，不要自行删插件或更换 DLL |
| 独立试听有声音，主游戏声音没变 | 当前工作范围 | 主游戏尚未迁移；记录试听结果，交给开发同事安排实际触发接入 |

## 9. 简短人工检查表

- [ ] 当前分支为 `audio/fmod-import`，Godot 为 4.7.2，Studio 为 2.03.06。
- [ ] “测试音频输出”可听见现有 WAV；没有把这个结果当作 Bank 事件通过。
- [ ] 三个必需 Bank 均来自同一次 Desktop Build，直接放在约定目录。
- [ ] F6 进入独立试听场景，加载后没有缺文件、缺事件、缺参数提示。
- [ ] 收集可以重复播放，每次自然结束。
- [ ] 吸取能够持续循环，停止后退出，也能再次开始。
- [ ] `Progress = 0 / 0.5 / 1` 符合设计；缓慢拖动连续、无异常爆音。
- [ ] 自定义事件路径可以播放和停止（本次有新增事件时检查）。
- [ ] 替换 Bank 后重载正常，重启场景后仍正常。
- [ ] 交付中保留源工程和素材来源说明，没有 FMOD Demo 媒体或账号信息。

Bank 到位前，可确认插件加载、试听界面、缺资源提示和 Core 的 WAV 输出；Bank 到位后才能确认 Bank 事件的真实解码、播放、参数驱动和设计听感。无声的接口检查、界面成功状态或 Core 试听不能作为最终音效验收。
