# 音频接入进度（给制作人）

音频更新：2026-10-09 · 分支：`audio/fmod-import`（2026-10-08 的吸尘器部分已合并到 `main`） · 负责人：Fred（音频）

这份文档记录主游戏里**哪些声音已经接入、什么时候会响、还差什么**。技术细节见同目录下的其他手册；这里只写玩法层面需要知道的内容。每次音频接入有进展都会更新这里。

## 一句话现状

吸尘器（开关机、黏液）、怪物（巢穴出现、出洞、随机叫声）、吸走怪物、拿到糖果、按钮和科技升级，以及主菜单和游戏中的背景音乐，已经通过 FMOD 接入。巢穴培育升级、驯服、通关音效暂时还是原来的 Godot 音效。钻头怪的声音已经做好，但游戏里还没有钻头怪，暂未接入。

**游戏里目前的怪物**：只有两种。史莱姆怪（粉色，开局就有）和黏液怪（蓝色，解锁捕网后出现）。钻头怪目前只在动画预览里，没有进入玩法。

## 已接入主游戏的声音

### 背景音乐

| 音乐 | FMOD 事件 | 什么时候播放 |
|---|---|---|
| 主菜单音乐 | `Mx_MainMenu` | 进入主菜单时开始，循环播放 |
| 游戏音乐 | `Mx_GamePlay` | 从主菜单点"开始"（或从预览列表进入近景 / 全景游玩）后开始，循环播放 |

- 循环在 FMOD 里做好（循环区域），游戏只负责开始和停止。
- 切换场景时，上一首音乐按 FMOD 里设置的淡出停止，新场景的音乐从头开始。主菜单 → 游戏 → 返回主菜单，每次都会切换到对应的音乐，两首不会长时间重叠。
- 淡出的长短由 FMOD 里音乐事件的设置决定（比如 Master 上的 AHDSR Release）；如果没有设置，就是直接停止。

### 按钮与科技升级（UI）

| 声音 | FMOD 事件 | 玩家什么时候会听到 |
|---|---|---|
| 悬停 | `UI/Button_Hover` | 鼠标移到任意可用按钮上（主菜单、工具栏、科技树节点等，所有场景通用）。不可用（灰掉）的按钮不响 |
| 点击 | `UI/Button_Click` | 点击任意按钮。购买 / 升级按钮除外，见下面两行 |
| 升级成功 | `UI/Button_Levelup` | 科技树里研究 / 解锁成功、工具栏弹出的吸管 / 捕网快速升级成功、巢穴"金色个体"科技购买成功 |
| 糖果不足 | `UI/Button_InsufPoint` | 糖果不够时点击上面这些购买按钮（按钮显示"还需 X 糖果"、呈灰色）。如果是因为前置科技没满足或已满级而灰掉，不响 |

- 购买按钮成功时只播"升级成功"，不再叠加普通点击声。
- 新加的按钮会自动带上悬停和点击声，不需要逐个配置。

### 吸尘器

| 声音 | FMOD 事件 | 玩家什么时候会听到 |
|---|---|---|
| 吸尘器开机 | `Vacuum_On` | 吸管锁定一只怪物、开始吸它的时候 |
| 吸尘器运转（循环） | `Vacuum_Loop` | 开机后持续响，由开机 / 关机自动控制，游戏不直接触发 |
| 吸尘器关机 | `Vacuum_Off` | 吸管手上没有目标约 0.2 秒后：吸完了、鼠标移开、切到捕网、切到星球总览、拖动视角、窗口失焦等；点"重开"会立即关机 |
| 吸到黏液 | `Slime_Enter` | 吸尘器开着时，吸管口进入地面黏液区域（黏液怪留下的拖痕、黏液怪巢穴周围的黏液地带） |
| 离开黏液（Pop） | `Slime_Exit` | 吸尘器开着时，吸管口离开黏液区域 |

### 怪物

| 声音 | 史莱姆怪 | 黏液怪 | 玩家什么时候会听到 |
|---|---|---|---|
| 巢穴出现 | `Monsters/Slime_NestAppear` | `Monsters/Mucus_NestAppear` | 游戏中途星球上长出一座新巢穴时。开局就在的两座史莱姆巢穴不播 |
| 出洞 | `Monsters/SlimeMon_Trigger` | `Monsters/MucusMon_Trigger` | 每只怪物从巢穴洞口刷出来时 |
| 随机叫声 | `Monsters/SlimeMon_Rand` | `Monsters/MucusMon_Rand` | 星球上有这种怪物时随机发出。数量越多叫得越频繁（见下方说明） |

**随机叫声的频率规则**（两种怪物各自独立计算）：

- 每只在星球上的怪物，平均每秒贡献 0.06 次叫声，大约每只 17 秒叫一次。
- 同一种怪物加起来最多每秒 1.2 次，怪物再多也不会更吵。
- 同一种怪物两次叫声之间至少间隔 0.25 秒，避免叠在一起。
- 例子：5 只史莱姆，大约每 3 秒叫一声；20 只及以上，达到上限，大约每秒 1 声多。
- 这三个数值都可以在 `scripts/monster_audio.gd` 里调整。

### 吸走与糖果

| 声音 | FMOD 事件 | 玩家什么时候会听到 |
|---|---|---|
| 吸走怪物 | `SuckUp_Pop` | 每只怪物被吸管吸走的那一刻（捕网抓到的不播） |
| 拿到糖果 | `Candy_Acquire` | 糖果飞进界面上糖果计数的那一刻（吸走或网到怪物都会有）。在星球总览里没有飞行动画，收集时立即播 |

**糖果连击音调（参数 `Candy_Combo`，0–1）**

- 跟随游戏里的连击数：连击 0 时为 0，每多一连击加 0.1，**第 10 连击及以后达到最高值 1**。
- 游戏的连击需要先在科技树里解锁"连击吸取"，并且只有吸管连续吸怪才算连击（两次之间不超过连击时限）。没解锁之前音调不会上升。
- 捕网一次网到多只不算连击，糖果音调为最低值。

### 听感上的设计意图（吸尘器）

- 吸管口在黏液里时，吸尘器的运转声会变闷（低通），离开时"啵"一声恢复清晰。
- 连续吸怪时，吸完一只后很快锁定下一只，吸尘器会一直开着，不会每只都关一次再开一次。
- 吸尘器关机时如果吸管口还在黏液里，会直接恢复清晰，不播"啵"声，避免关机时出现奇怪的 Pop。
- 只有吸尘器开着时，黏液声才会触发；吸管空着划过黏液不会出声。

## 需要制作人留意的点

- **试听方式**：打开项目按 F5 运行主游戏即可。鼠标悬停怪物开始吸；黏液怪巢穴解锁后，去有黏液的地面上吸怪，可以听到黏液效果。
- **开机时机是"锁定怪物"而不是"鼠标在星球上"**：只有真正在吸东西时吸尘器才响，空闲时安静。如果试玩觉得开关太频繁，可以改成"吸管在星球表面就开机"，或者调长 0.2 秒的关机缓冲。
- **原来的收集音效（WAV）已被替换**：吸走怪物改为 `SuckUp_Pop`，糖果到账改为 `Candy_Acquire`。如果 bank 缺失或加载失败，会自动退回原来的 WAV，游戏不会没声音。
- 怪物声音是全局的（2D），不分左右、不随距离变小，在星球总览里也能听到。
- 切到星球总览、移到 UI 上时，吸管口会被视为离开黏液，可能先听到一声 Pop 再关机。试玩时如果觉得别扭，请反馈。

## 更新声音的流程

音频同事在 FMOD Studio 里改完声音后，Build 出三个文件（`Master.bank`、`Master.strings.bank`、`ProjectVacuum.bank`），覆盖到项目的 `bank/Desktop/` 文件夹即可。只要事件名不变，游戏不需要改代码。
