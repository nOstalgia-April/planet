# 音频接入进度（给制作人）

最后更新：2026-10-08 · 分支：`audio/fmod-import` · 负责人：Fred（音频）

这份文档记录主游戏里**哪些声音已经接入、什么时候会响、还差什么**。技术细节见同目录下的其他手册；这里只写玩法层面需要知道的内容。每次音频接入有进展都会更新这里。

## 一句话现状

吸尘器（吸管）的开关机声和"吸到黏液"的声音已经通过 FMOD 接入主游戏，可以在 Demo 里直接听到。其余音效（收集、升级、驯服、通关）暂时还是原来的 Godot 音效，没有迁移。

## 已接入主游戏的声音

| 声音 | FMOD 事件 | 玩家什么时候会听到 |
|---|---|---|
| 吸尘器开机 | `Vacuum_On` | 吸管锁定一只怪物、开始吸它的时候 |
| 吸尘器运转（循环） | `Vacuum_Loop` | 开机后持续响，由开机 / 关机自动控制，游戏不直接触发 |
| 吸尘器关机 | `Vacuum_Off` | 吸管手上没有目标约 0.2 秒后：吸完了、鼠标移开、切到捕网、切到星球总览、拖动视角、窗口失焦等；点"重开"会立即关机 |
| 吸到黏液 | `Slime_Enter` | 吸尘器开着时，吸管口进入地面黏液区域（黏液怪留下的拖痕、黏液怪巢穴周围的黏液地带） |
| 离开黏液（Pop） | `Slime_Exit` | 吸尘器开着时，吸管口离开黏液区域 |

**听感上的设计意图**

- 吸管口在黏液里时，吸尘器的运转声会变闷（低通），离开时"啵"一声恢复清晰。
- 连续吸怪时，吸完一只后很快锁定下一只，吸尘器会一直开着，不会每只都关一次再开一次。
- 吸尘器关机时如果吸管口还在黏液里，会直接恢复清晰，不播"啵"声，避免关机时出现奇怪的 Pop。
- 只有吸尘器开着时，黏液声才会触发；吸管空着划过黏液不会出声。

## 还没有接入 / 待定

| 项目 | 现状 |
|---|---|
| 收集成功、升级、驯服、通关音效 | 仍用原 Godot 音效，尚未迁移到 FMOD |
| 捕网相关声音 | 未制作 |
| 吸取进度（两阶段：拔出 → 吸入）的声音变化 | 讨论过，未实现；当前吸尘器声音不随吸取进度变化 |
| 吸管升级后声音是否变化 | 未设计 |
| FMOD 里"防止误触 Pop"的保护条件 | 可选；游戏这边已保证只在真正离开黏液时播 Pop |

## 需要制作人留意的点

- **试听方式**：打开项目按 F5 运行主游戏即可。鼠标悬停怪物开始吸；黏液怪巢穴解锁后，去有黏液的地面上吸怪，可以听到黏液效果。
- **开机时机是"锁定怪物"而不是"鼠标在星球上"**：只有真正在吸东西时吸尘器才响，空闲时安静。如果试玩觉得开关太频繁，可以改成"吸管在星球表面就开机"，或者调长 0.2 秒的关机缓冲。
- 切到星球总览、移到 UI 上时，吸管口会被视为离开黏液，可能先听到一声 Pop 再关机。试玩时如果觉得别扭，请反馈。

## 更新声音的流程

音频同事在 FMOD Studio 里改完声音后，Build 出三个文件（`Master.bank`、`Master.strings.bank`、`ProjectVacuum.bank`），覆盖到项目的 `bank/Desktop/` 文件夹即可。只要事件名不变，游戏不需要改代码。
