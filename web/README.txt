星球清扫计划 — 网页版

本机试玩（Windows）：
1. 解压完整文件夹。
2. 双击 start-web.cmd（需要 Python 3）。
3. 浏览器加载完成后点击“点击进入游戏”，开启声音。
4. 结束后关闭启动器窗口；也可以在窗口中按 Ctrl+C。

请通过启动器打开，不要直接双击 index.html。
存档保存在当前浏览器、当前网址的本地存储中。换浏览器、换端口或清除网站数据会使用不同存档。

网站部署：
将整个文件夹上传到静态网站，入口为 index.html，保留全部相对路径。
服务器需要以 application/wasm 提供 .wasm 文件。
当前为单线程版本，无需额外配置跨域隔离响应头。
建议为 .pck、.wasm 和 .js 启用服务器压缩；首次资源加载较大。

验证目标：Windows 桌面版 Edge / Chromium，鼠标和键盘操作。
当前包含桌面 GPU 纹理格式，手机浏览器与触控操作尚未验证。
