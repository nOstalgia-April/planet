# 巢穴与怪物调节预览

主菜单 → 预览 → 巢穴与怪物调节。也可以 F6 运行 `art_alignment_preview.tscn`。

预览隐藏底部游戏工具栏。顶部菜单点击“收起”后关闭面板，只保留左上角的“展开菜单”按钮；展开后保留原选择及调节参数。原图画廊随菜单折叠向上扩展。

预览使用正式近景星球及原有物件场景。左到右为史莱姆、黏液、地鼠；选择阶段查看三种巢穴，选择具体巢穴时自动切到该阶段。可统一调全部物件、所有巢穴、所有怪物，也可分别调每种巢穴的四个阶段与每种怪物。怪物静止，地鼠保持冒头动画，便于比较大小。产出按钮查看各阶段产怪／花朵产出；朝向滑条查看不同地壳纹理。

星球预览中巢穴与花朵按原始 PNG 的 1:1 窗口像素尺寸显示；怪物按既有素材的显示基准，保留高清图的缩小和接地点校准。巢穴、产怪、花朵的预览实例移除每张素材的缩放轨道、花朵父节点倍率及角色 0.36 美术倍率；原有贴图锚点按素材倍率换算回原图单位。预览统一抵消世界视角与窗口画布的缩放，窗口尺寸或视角变化时重新计算，一个 PNG 像素对应一个窗口像素，不额外缩小素材。界面的大小倍率在此 1:1 基准上相乘；倍率为 1 时，史莱姆待机 PNG 的 89×75 画布显示为 89×75 窗口像素。下沉量相加，正值下沉，负值抬起，单位为世界单位。曲面贴地在巢穴下沉之外增加曲率修正，可独立关闭。

普通巢穴额外下沉默认从 8 调为 0，保留曲面修正。所有物件保留原造型及原图大小差异；不再单独缩小地鼠或把不同物种校准到接近的大小。

编辑只影响预览副本；动画库也使用独立副本，正式游戏和原始独立动画场景保留现有尺寸校准。点击“保存到游戏”仅将界面的附加倍率和下沉量写入 `resources/art_presentation.tres`，返回主菜单后开始新游戏生效；正式游戏仍叠加自身的美术校准，因此它的绝对尺寸与原图基准预览不同。关闭预览不保存。恢复默认将当前预览恢复为全部倍率 1、额外下沉 0、曲面贴地开启，仍需点击保存才写回游戏。巢穴间距在新游戏中按最大倍率重新计算。

中央活动区仍沿用正式游戏的工具栏包围盒加 32 个界面单位的余量计算，底部工具栏在此预览中隐藏。沿整颗星球保留同一个圆带，旋转、切换全景不改变它；窗口尺寸改变时重新计算并把怪物位置与移动目标投回圆带。绿线为外沿，橙线为中央避让边界。

## 验证

`tests/art_alignment_check.tscn` 检查两种分辨率、18 个选择项、12 种巢穴显示、每项独立修改、参数序列化、捕获点随显示下沉和全物种圆带限制。原图基准检查覆盖所有动画的缩放关键帧、花朵父节点倍率、各阶段非透明宽度、巢穴／花朵／怪物的水平和垂直 1:1 窗口像素映射、怪物 PNG 画布的实际显示宽高，以及正式动画库未被预览改写。加 `-- --capture` 输出实机截图到 `artifacts/art_alignment/`。

2026-10-10 原图 1:1 显示已通过 Godot 4.7.2 的 1280×800／1920×1080 检查，核对史莱姆 89×75、黏液怪 101×72、地鼠 156×164 原图画布与窗口显示像素一致。大尺寸巢穴按原像素显示，可能超出当前可见区域；原图画廊保留滚动查看。截图检查使用强制绘制以支持隐藏窗口。现有 gdformat 仍无法解析项目的带类型循环，真实源码以引擎解析和实机检查为准。

本轮已通过 Godot 4.7.2 的预览实机检查（1280×800、1920×1080）、钻头怪专项、巢穴间距与宽地壳专项，查看了四阶段截图。旧 `slime_roaming_check.gd` 仍要求角色径向朝外、全景使用不同岸线，与当前保持屏幕正立、近远景同一地表的规则不符，未作为通过项；新检查直接验证三物种位置始终留在圆带内。现有 gdformat 不支持 Godot 4.7 的带类型循环，能处理的脚本及移除循环类型标注的检查副本已格式核对，真实源码以引擎解析为准。

## 原图 100% 与正式角色美术（2026-10-10）

点击“原图 100%”或按 N，进入所选对象的原图画廊；再次按 N／点击“返回星球预览”恢复 1:1 像素星球预览。画廊中同样一个 PNG 像素对应一个屏幕像素，透明留白完整保留，并显示当前帧的画布大小；所有对象、巢穴组、怪物组和单个物种均可选择，过大的图案可横向／纵向滚动。此对照模式不改保存倍率，原有“恢复默认”仍恢复附加倍率 1。

正式角色复用 `scenes/物品动画/史莱姆.tscn`、`黏液怪.tscn`，由 `scenes/world/slime_art.tscn` 组合。原 PNG、原始独立动画场景未改写。粉色跳跃七帧按现有 0.38 秒出巢过程播放，随后返回待机；黏液怪只有待机素材，沿用原移动与出巢位移。基础 0.36 美术倍率保留原图比例，并接入现有每物种大小／下沉设置；巨型按已有体型倍率放大。吸取、黏液脱附及数量标记复用规则，捕获中心和可见范围按当前帧的非透明图案计算。

新增 `tests/formal_slime_art_check.tscn` 覆盖正式贴图、待机／跳跃、金色、巨型、独立调节与吸取几何；预览检查增加两种分辨率下 1:1 实际屏幕像素、透明画布完整尺寸及往返时不改倍率的断言。吸取边界与巨型玩法回归也已通过。

本轮复用完整 `runtime_art_integration_check.gd` 实机检查，角色、吸取、捕网和原有流程未出现其他失败，但取消普通巢穴额外 8 单位下沉后，部分旋转朝向的旧巢穴贴地断言仍失败（沿不规则轮廓允许 2 世界单位的误差）。本轮没有修改巢穴接地算法；此项单独记录，不计入本轮通过项。

## 高清图的尺寸基准（2026-10-11）

怪物星球预览保留正式动画中的高清归一化比例和锚点，仍移除外层0.36玩法倍率，避免新图按363×303、395×281或更大的地鼠画布撑大角色。已有倍率参数无需按分辨率重新调整。“原图100%”画廊继续展示完整高清画布；这与正式游戏里的缩小显示是两个视图。高清来源与逐帧校准记录在 `assets/物品动画/高清怪兽/来源与缩放.json`。上方历史原图尺寸报告是10月10日导入时的旧图记录。
