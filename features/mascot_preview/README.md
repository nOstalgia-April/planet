# 看板娘入场与待机预览

在 Godot 中打开 `mascot_preview.tscn`，按 F6 独立运行。左上角可切换斗篷、肌肉、小史莱姆，支持重播、暂停和半速播放。快捷键：1 / 2 / 3、R、空格。

角色停在右下角；默认右侧留 48、底部留 42 个逻辑像素。三种形态显示高度分别为 340、280、150，可在 `scenes/ui/mascot_presenter.tscn` 的检查器调整。

素材来源是用户指定的微信 2026-10 目录：斗篷与肌肉形态使用“看板娘补充”中的入场和待机；小史莱姆使用“补充部分/看板娘待机3”的四帧待机，通过程序平移入场。这里只导入本次需要的 24 帧。

原始入场帧已包含位移和回弹，保持完整透明画布，不逐帧裁切。对齐采用待机整体可见边界，入场与待机共享位置和缩放。原素材未标明帧率，当前预览暂设入场 8 帧/秒；斗篷待机每帧停留 0.6 秒（完整循环 1.2 秒），其余待机 5 帧/秒，可在 `resources/mascot/*.tres` 中修改。小史莱姆平移时长暂设 0.75 秒。

背景直接复用正式素材 `assets/场景动画/全景背景/001.png`；布局按用户要求采用右下角呈现。本场景未接入正式剧情触发或修改主场景。

2026-10-13 验证：在本机 Godot 4.6.1 实际渲染三种形态，检查入场接待机、切换、暂停、重播和 1280×720 / 1280×800 布局。本机 gdformat 较旧，无法识别预览脚本的带类型 for 循环，采用引擎解析结果；项目声明的 4.7 环境本次未验证。捕获进程退出时有纹理释放警告，播放与截图检查完成。

`output/mascot-preview.html` 为同素材与时序的独立浏览版，可直接打开，支持同样的按钮。窄浏览面板会适当放大角色以便查看，精确游戏布局以 Godot 场景为准。
