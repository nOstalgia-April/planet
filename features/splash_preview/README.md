# 中央喷溅独立预览

在 Godot 打开 `features/splash_preview/splash_preview.tscn`，按 **F6** 运行当前场景。四个区域共用本次概念图的中央喷溅轮廓，默认同色、同尺寸、同进度播放。

| 效果 | 可比较的变化 |
| --- | --- |
| 弹性回弹 | 整体压缩、撑开、过冲回弹，作为单张贴图基础对照 |
| 局部甩动 | 不同突起错开时间伸展和回缩，局部轮廓独立变化 |
| 扭转回弹 | 中心与外缘产生不同程度的扭转，再回到原形 |
| 泼溅飞散 | 主体撑开、突起甩出，附带小液滴向外飞散 |

**同步重播**恢复四种效果的同步播放；点击任意区域，只重播该效果。**暂停／继续**控制播放，拖动**进度**会自动暂停，便于逐段比较。支持红、蓝、绿染色、自动循环和强度调节。快捷键：`R` 同步重播，`空格` 暂停／继续。

默认直接使用 `assets/splash_preview/source_concept.png` 中中央原始 **45 × 44 像素轮廓**，由 shader 裁取并抠掉背景。`assets/splash_preview/central_splash.png` 是基于原图放大重建的透明 PNG 备选，轮廓存在重建差异。原始截图分辨率较低，放大显示也会保留这个限制。

另提供 `assets/splash_preview/central_splash_original.png`：由 Godot 在透明 SubViewport 中渲染导出的 **66 × 64 像素原始轮廓 PNG**，包含留白，未使用放大重建素材。

每种效果是 `effects/` 下可单独实例化的场景，不依赖星球或主玩法。

常用参数在效果根节点检查器中调整：`duration`（默认 1.6 秒）、`display_size`（默认 180）、颜色与强度。效果统一提供 `set_tint(Color)`、`set_intensity(float)`、`play()` 和 `seek(float)` 接口；预览使用同一时钟驱动 `seek`。飞散液滴属于程序表现，并非逐帧美术素材。

强度大于 1 时，预览会统一缩小四组效果，为更远的飞散液滴保留空间。四组仍保持同色、同尺寸；强度 0～1 的预览尺寸保持原设置。

本预览提供代码变形的效果比较，不是流体模拟。它展示了单张轮廓能做到的动态范围；真实断裂、重新融合和复杂手绘笔触仍需要另外设计。

`features/splash_preview/capture_preview.gd` 用于导出原轮廓并验证显示：保存 1280 × 800、1920 × 1080 的四种效果截图，以及蓝色、强度 2 在 0.3 秒和 0.55 秒的对比。截图位于 `artifacts/splash_preview/`；`frames/` 下保存 30 fps 的同步播放帧（48 帧动画＋9 帧定格），可用于生成动图。

实际检查：Godot 4.7.2 启动与 shader 编译通过，已查看两种尺寸下的多时刻画面和蓝色最大强度截图。动图为 `artifacts/splash_preview/splash_comparison.gif`。效果脚本格式检查通过；预览脚本因本机格式工具不支持 typed for，在移除循环类型标注的临时副本上通过，其原始语法由目标引擎验证。
