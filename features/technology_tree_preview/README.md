# 科技树预览

正式游戏、主菜单中的科技树预览与科技调参工具共用 `scenes/ui/interactive_technology_page.tscn`。

## 2026-10-14 状态层级

当前节点常驻名称、等级和价格；只有可购买项保留粉色光晕与轻呼吸，缺钱降亮度，锁定保留名称与灰粉锁，满级勾号加 MAX 且不发光。选中叠加原墨迹。左侧 248 宽固定详情不遮挡树，移出节点后保留便于购买，关闭页面清除；直接点击节点仍可购买。关键工具／巢穴／自动化加大原图标，顶部提示下一关键解锁及真实前置条件。原 PNG 无改动、无生成图片。

本轮参考沿用并实际查看 `docs/references/technology-tooltip-hierarchy-reference.png` 与 `dirt-clicker-technology-reference.png`，仅采用状态可见与费用／效果分层。下方日期章节记录历史方案；现行行为及验证见项目 README 的「科技树决策状态与纹理保留」。

## 2026-10-13 固定布局与全屏背景

- 科技树主题统一使用 `fonts/technology_font.tres`：保留 Oldenburg 数字、西文及站酷小薇中文，给本页字体副本启用 MSDF 平滑缩放，覆盖标题、余额、等级、价格和详情。满级文字沿用亮奶白色与较细深色描边。
- 糖果图标保留白色描边，三处 UI（游戏余额、科技节点价格、详情价格）统一使用线性 mipmap 采样；缩小时平均掉低于像素大小的描边颗粒，减少锯齿。此次实机截图位于 `artifacts/technology_all_smooth_20261013/`，含两种分辨率、详情、最大缩放与游戏余额图标。
- 最新视觉按用户要求恢复原 `halo.tres` 粉色光晕与白色图标；移除常驻深色墨团与描边。悬停／键盘聚焦时隐藏光晕、显示原黑色 `hover_blob.tres`，移开恢复；锁定依然显示锁与前置提示，费用和购买规则保持原逻辑。
- 右侧以巢穴培育为根，高价值／巨型个体分居中层两侧，完全自动化位于顶层并与培育对齐。自动化与其余节点同尺寸，仅以显露后的常驻名称提示终局定位，不给高价值／巨型添加额外前置条件。
- 最新实机截图为 `artifacts/technology_brush_curves_20261013/`，包含原图笔刷背景、弯曲虚线、黑色悬停、同尺寸自动化节点与最大缩放。

- 退出涂鸦接入当前种群配色，独立预览默认使用酒红／粉色系；正式游戏中跟随科技树背景切换。缩放达到节点或价格即将越界的尺寸时停止继续放大。

## 预览和调参

打开 `technology_tree_preview.tscn` 按 F6，底部可切换开局、可购买、成长中和高阶四种状态。预览使用真实购买模型，不保存研究进度。

打开 `res://features/technology_editor/科技树调参.tscn`，在中文表单中修改数值，在「科技树试买」核对价格和效果；保存后进入正式游戏查看。数值、前置与全局研究规则沿用现有模型。

旧背景特效的对照场景仍独立保留；正式背景使用本轮版式2原图。
