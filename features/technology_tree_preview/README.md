# 科技树预览

正式游戏、主菜单中的科技树预览与科技调参工具共用 `scenes/ui/interactive_technology_page.tscn`。

## 2026-10-12 降噪与交互层级

- 沿用下述用户版式与节点价格参考：节点以原有悬停墨团素材作为常驻的不规则底板，等级放在墨团内，价格紧贴墨团下方；状态标记放在内侧。
- 正式底图仍为原版酒红素材；显示时降低饱和度和反差，中央混合平缓酒红渐变，将明显颗粒保留在外围。原始 PNG 不变。
- 可购买节点使用粉色边缘与小加号，余额不足弱化图标和边缘，满级撤掉光晕并显示小勾，未解锁保留灰锁。取消节点持续呼吸；悬停或键盘聚焦时强调当前底板。
- 悬停浮窗保留原有墨迹底图，通过独立材质将粉色光晕透明度降至原来的 28%，正文不受该材质影响。
- 保持直接点击购买、悬停详情、拖动和平移缩放。以下“版式2美术”记录初次接入，节点表现以本节为准。

## 2026-10-12 版式2美术

- 以用户提供的「板式2/位置参考.png」为版式依据：酒红颗粒背景、粉色节点光晕、白色图标、弯曲虚线，左侧笔刷按钮用于离开。
- 右侧固定详情栏已移除。悬停节点显示名称、效果及必要条件，移开即隐藏；直接点击节点购买。拖动超过 8 像素后松手不购买。
- 浮窗跟随鼠标，以悬停图标的屏幕位置决定向左／右、上／下偏移，鼠标在图标内移动不会改变方向；留出光标间隙并限制在屏幕内。信息依次为名称、当前等级／上限、短效果、较大字号本次增量与小号当前值、必要条件、底部购买价格；满级展示当前效果并隐藏价格。
- 前置未满足的后续节点只显示灰色锁，隐藏实际图标、等级和费用；悬停仅提示解锁条件。满足前置后露出实际科技图标，捕网使用网格图标，锁不是某项科技的固定图标。
- 已显露节点右下常驻当前等级／上限，下方显示糖果图标和价格。糖果贴图始终保留原色，仅价格数字区分状态：可购买为亮绿，余额不足为橙红；满级以「已满级」替代价格。单纯余额不足不会将节点隐藏成锁。
- 节点拖动、右键平移和滚轮缩放继续可用。左下角缩放条、百分比和恢复布局按钮已移除；再次进入科技树沿用上次缩放，包括本次游戏内重新创建的菜单。离开或 Esc 返回游戏，研究进度保留。
- 各入口使用用户图2的白色箭头光标；吸尘器作为游戏光标出现时隐藏箭头，离开吸尘器状态后恢复。

源 PNG 原样复制到 `assets/ui/technology/`，透明留白用 AtlasTexture 区域处理，没有重绘。板式2的节点图标与「板式1/图标」中的独立素材一致，因此复用独立图标；背景与浮窗底板取自板式2。逐文件来源和 SHA-256 见该目录的 `sources.json`。光标像素已与用户附件核对一致。

参考保存在 `docs/references/technology-layout-2.png` 和 `technology-node-price-reference.png`。后者只用于等级、费用与购买能力提示的位置和层级，不引入其像素风、题材或背景。

浮窗信息层级参考用户提供的 `technology-tooltip-hierarchy-reference.png`：名称置顶、等级弱化、效果短句、增量与当前值并排、绿色购买和货币价格置底。采用这些阅读顺序，沿用本项目底板、字体和原色糖果贴图。

## 预览和调参

打开 `technology_tree_preview.tscn` 按 F6，底部可切换开局、可购买、成长中和高阶四种状态。预览使用真实购买模型，不保存研究进度。

打开 `res://features/technology_editor/科技树调参.tscn`，在中文表单中修改数值，在「科技树试买」核对价格和效果；保存后进入正式游戏查看。数值、前置与全局研究规则沿用现有模型。

旧背景特效的对照场景仍独立保留；正式背景使用本轮版式2原图。
