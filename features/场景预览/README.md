# 场景美术独立预览

F5 打开 `scenes/主菜单/主菜单.tscn`；**start** 跳转到近景游玩预览。主菜单的「预览」可进入下面五个场景，也可以在 Godot 中打开任意一个按 F6 运行。

| 场景 | 内容 |
| --- | --- |
| `近景游玩预览.tscn` | 灰色近景星球 6 帧，近景颜色背景与暗角各 5 帧；复用现有玩法和 HUD |
| `全景游玩预览.tscn` | 灰色全景星球与背景各 3 帧；从全景开始，保留生态统计与旋转 |
| `吸尘器预览.tscn` | 7 帧、7 帧/秒，循环工作动画 |
| `捕网预览.tscn` | 5 帧、5 帧/秒，投出到展开；播完停留 0.8 秒后重播 |
| `黏液怪移动预览.tscn` | 9 帧、5 帧/秒，原画移动与拖尾动画 |

动作预览提供暂停、重播、逐帧与滑条；空格暂停/继续、R 重播、左右键逐帧。所有页面都有返回主菜单的按钮。近景与全景中的按钮或原有滚轮可以切换视角，同一局的进度与实体不会重新生成。主菜单重新点击 start 开始新的一局。

## 素材与场景

- 本轮素材放在 `assets/场景动画/`，目录使用中文，动画帧编号为 `001.png` 起。`来源与命名.json` 记录来源、帧率和 SHA-256；50 张 PNG 均保留原文件内容。
- 不导入星星/月亮图层、彩色恢复素材、位置参考合成图。红色背景保留为独立图层，不随地表旋转。
- 近景原图为 7866×8119，Godot 导入设置 `process/size_limit=4096`；源文件未缩小。星球贴图按实际导入尺寸与归一化中心适配现有半径，不把透明画布的中心误当作球心。
- `scenes/场景动画/` 内为可复用原生场景，贴图与 AnimationPlayer 可直接在编辑器调整。动画资源 ID 使用 ASCII，文件、节点与动作名使用中文。独立物件不自动播放，预览或背景实例负责启动。
- 近景游玩预览继承 `scenes/disk_demo.tscn`；`星球地表.gd` 保留 PlanetSurface 的空间接口，只替换显示。全景入口继承同一预览，以全景作为初始视角。
- 吸尘器与捕网已通过 `scenes/world/pipe_cursor.tscn`、`capture_net.tscn` 接入实际玩法。吸尘器在可操作地表循环工作，捕网帧由投出/收拢进度驱动；独立预览仍保持原始 7／5 帧每秒。捕网源目录标注为「旧网」，没有收网与携带序列，玩法中的收拢使用展开原画缩放。角色外观本次保留原样，黏液怪移动仅供独立预览。

## 参考范围

封面采用本批 `封面/参考位置.png` 的构图与 Start 主按钮位置；第二个按钮作为此次预览入口。近景、全景采用本批各自位置参考。地表仍沿用项目既有的宽弧形地壳与底部工具栏位置；已查看 `docs/references/reus-wide-ground-reference.png`，仅沿用其弧形地面与操作区的分离，不加入图中的装饰、角色或功能。

## 检查

`tests/场景预览检查.gd` 检查六个入口、帧率、逐帧暂停、捕网单次结束、视角切换保留同一局与巢穴位置，以及 Start/返回菜单的实际场景跳转。加 `-- --capture` 使用实际渲染导出 1920×1080、1280×800 截图到 `artifacts/scene_art_audit_2026_10_08/`。

2026-10-08 已通过 Godot 4.7.2 无界面行为检查、D3D12 实机行为检查和脚本格式检查；已查看六个入口的两种分辨率画面。实机日志无脚本、资源或渲染错误；另外核对了全部 50 张 PNG 的校验值与排除范围。
