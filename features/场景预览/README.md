动作预览提供暂停、重播、逐帧与滑条；空格暂停/继续、R 重播、左右键逐帧。所有页面都有返回主菜单的按钮。近景与全景中的按钮或原有滚轮可以切换视角，同一局的进度与实体不会重新生成。主菜单重新点击 start 开始新的一局。

视角切换默认用 0.8 秒，两个视角共用一个星球合成画面、球心、半径、旋转及动画时钟。近景使用高清 6 帧，接近全景时用约 0.22 秒短渐变换成美术提供的全景 3 帧；拉近时在星球仍小时换回高清图。两套图按实际圆形外沿校准，高清图相对全景图顺时针旋转 90° 后地形朝向对应。使用预乘透明度的单次混合，避免普通双层淡化造成重叠地壳变暗或透背景。近景仍是等比放大后裁切星球顶部，不将近景横向拉成 1.65 倍。近景按用户提供的 4000×2251 构图校准：共享贴图相对素材固定顺时针旋转 90°，地平线约在视口高度的 48.54%，星球半径为视口宽度的 68.85%，球心较屏幕中心向右偏移屏宽的 0.65%。全景纹理在合成时补偿两套原图的朝向差，随后共同跟随世界旋转。背景与生态信息仍在后段渐变。缩放过程中只附带轻微的镜头拉扯，不做明显压扁与回弹；两端恢复完全等比。动画中固定当前朝向，暂时禁止拖转、悬停捕获和新投网；重复同向滚轮不重播，反向滚轮从当前画面平滑返回，重开立即取消过渡。全景独立入口直接从全景开始。

`PlanetViewController` 的 `transition_seconds` 调整时长（默认 0.8），`transition_pull` 调整镜头拉扯幅度（默认 0.02，设为 0 后全程严格等比），`near_radius_ratio`、`near_horizon_ratio` 与 `near_horizontal_offset_ratio` 分别调整近景半径、地平线和水平偏移；本预览覆盖为 0.68853、0.48544、0.0065，基础灰盒控制器保留 0.60、0.55、0。近景的平缓程度来自放大裁切，地心不再按工具栏高度硬留一条空白带。控制器拥有过渡进度；`projection_changed` 仅同步轻量显示，`view_changed` 负责模式切换时的交互状态。仅验证端点的旧测试与全景初始化使用 `zoom_steps(steps, false)` 跳过动画。

`scenes/场景动画/双视角星球.tscn` 继承高清星球场景，`scripts/场景动画/双视角星球.gd` 管理全景纹理序列和合成参数。`blend_start_zoom = 0.28`、`blend_end_zoom = 0.02` 指定接近全景的换图区间（0 为全景、1 为近景），默认对应拉远约 0.52～0.73 秒；混合比例由当前缩放位置决定，反向或布局刷新不重置。全景图球心约为原图 `(950.6, 551.1)` 像素，圆形主体半径 372 像素；树木等外沿装饰不计入半径。两套素材均为 5 FPS，3 帧序列在高清 6 帧周期内循环两次。
