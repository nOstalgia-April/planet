# 场景美术独立预览

F5 打开 `scenes/主菜单/主菜单.tscn`；**start** 跳转到近景游玩预览。主菜单的「预览」可进入下面十一个页面，也可以在 Godot 中打开任意一个按 F6 运行。

| 场景 | 内容 |
| --- | --- |
| `近景游玩预览.tscn` | 灰色近景星球 6 帧，近景颜色背景与暗角各 5 帧；复用现有玩法和 HUD |
| `全景游玩预览.tscn` | 与近景共用高清星球 6 帧，全景背景 3 帧；从全景开始，保留生态统计与旋转 |
| `吸尘器预览.tscn` | 7 帧、7 帧/秒，单次管内输送；播完停留 0.8 秒后重播 |
| `捕网预览.tscn` | 5 帧、5 帧/秒，投出到展开；播完停留 0.8 秒后重播 |
| `黏液怪移动预览.tscn` | 9 帧、5 帧/秒，原画移动与拖尾动画 |
| 物件与巢穴 | 九类物件的全部动作，含三种巢穴完整与分段升级；巢穴 12 帧/秒，小花 5 帧/秒，其他物件 8 帧/秒 |
| 中央喷溅 | 弹性回弹、局部甩动、扭转回弹、泼溅飞散四种效果 |
| 史莱姆吸取 | 吸力、完整吸取与慢放 |
| 地球仪 | 球面旋转、缩放与怪物显示 |
| 科技树 | 四种进度状态与购买反馈；关闭页面返回主菜单 |
| 花朵地块染色 | 平面颜料沿大弯轮廓蔓延，结束后从积料下沿挂滴；双花／单花、覆盖顺序、大小、随机形状和重播 |

动作预览提供暂停、重播、逐帧与滑条；空格暂停/继续、R 重播、左右键逐帧。所有页面都有返回主菜单的按钮。近景与全景中的按钮或原有滚轮可以切换视角，同一局的进度与实体不会重新生成。主菜单重新点击 start 开始新的一局。

视角切换默认用 0.8 秒，两个视角始终使用同一个高清星球实例、球心与动画进度。远景是整张高清图缩小，近景是等比放大后裁切星球顶部，不再切换、淡化星球纹理，也不再将近景横向拉成 1.65 倍。近景按用户提供的 4000×2251 构图校准：共享贴图相对素材固定顺时针旋转 90°，地平线约在视口高度的 48.54%，星球半径为视口宽度的 68.85%，球心较屏幕中心向右偏移屏宽的 0.65%。这一旋转同时作用于近远景，切换时不改变纹理朝向。背景与生态信息仍在后段渐变。缩放过程中只附带轻微的镜头拉扯，不做明显压扁与回弹；两端恢复完全等比。动画中固定当前朝向，暂时禁止拖转、悬停捕获和新投网；重复同向滚轮不重播，反向滚轮从当前画面平滑返回，重开立即取消过渡。全景独立入口直接从全景开始。

`PlanetViewController` 的 `transition_seconds` 调整时长（默认 0.8），`transition_pull` 调整镜头拉扯幅度（默认 0.02，设为 0 后全程严格等比），`near_radius_ratio`、`near_horizon_ratio` 与 `near_horizontal_offset_ratio` 分别调整近景半径、地平线和水平偏移；本预览覆盖为 0.68853、0.48544、0.0065，基础灰盒控制器保留 0.60、0.55、0。近景的平缓程度来自放大裁切，地心不再按工具栏高度硬留一条空白带。控制器拥有过渡进度；`projection_changed` 仅同步轻量显示，`view_changed` 负责模式切换时的交互状态。仅验证端点的旧测试与全景初始化使用 `zoom_steps(steps, false)` 跳过动画。

## 素材与场景

- 本轮素材放在 `assets/场景动画/`，目录使用中文，动画帧编号为 `001.png` 起。`来源与命名.json` 记录来源、帧率和 SHA-256；50 张 PNG 均保留原文件内容。
- 不导入星星/月亮图层、彩色恢复素材、位置参考合成图。红色背景保留为独立图层，不随地表旋转。
- 巢穴位于地壳后方（`Nests.z_index=-1`）。背景由 `scenes/场景动画/背景地壳裁剪.tscn` 按现有地壳外轮廓扣除星球覆盖区，地壳贴图的透明处露出黑色底，不再透出红色背景。裁剪随星球转动和视角缩放，背景画布仍固定在视口中。
- 正式巢穴的 `near_nest_scale` 在基础玩法场景中设为 `(0.4, 0.4)`，继承到近景与全景预览，覆盖两种巢穴、升级动画和自动化花。按用户红圈参考的洞穴主体校准，1920×1080 近景中的首次升级史莱姆洞穴完整图案约为 336×217 像素；悬停范围、接地和生成占地沿用实际显示尺寸自动计算。
- 各等级保留素材天然的尺寸差异，基础倍率相同，但不把不同等级归一到同一宽高。史莱姆大小独立于巢穴等级；是否增加分级缩放，等用户查看实机后决定。
- 占位怪物的 `near_slime_scale=0.64`，独立于巢穴的 0.4 校准；粉色个体含轮廓宽约 105 像素，约为首次升级洞穴宽度的 1/3，接近用户参考中的相对大小。保留占位造型，身体中心捕获点随尺寸同步。吸尘器贴图缩放为 0.144，实际吸取半径 9.6；捕网预览、展开图案和实际捕获半径均为 33.6，数量、冷却和结果反馈按工具比例适配。黏液覆盖半径 44.8，拖痕半宽 2.8、最大长度 28.8、采样间距 1.0，绘制与接触判定共用尺寸。
- 近景原图为 7866×8119，Godot 导入设置 `process/size_limit=4096`；源文件未缩小。星球贴图按实际导入尺寸与归一化中心适配现有半径，不把透明画布的中心误当作球心。
- `scenes/场景动画/` 内为可复用原生场景，贴图与 AnimationPlayer 可直接在编辑器调整。动画资源 ID 使用 ASCII，文件、节点与动作名使用中文。独立物件不自动播放，预览或背景实例负责启动。
- 近景游玩预览继承 `scenes/disk_demo.tscn`；`星球地表.gd` 保留 PlanetSurface 的空间接口，只替换显示。全景入口继承同一预览，以全景作为初始视角。
- 正式游玩中 `PlanetSurface/星球画面` 是唯一星球画面，使用 `scenes/场景动画/近景星球.tscn` 的高清序列。旧的全景素材保留在资源目录供独立查看，正式切换不再使用另一套低清图和独立动画。
- 吸尘器与捕网已通过 `scenes/world/pipe_cursor.tscn`、`capture_net.tscn` 接入实际玩法。吸尘器管内输送由 `PipeCursor` 的待机／单次／连续状态控制：`play_capture()` 只在实际收集成功后启动，空吸、未完成吸入和黏液脱附不启动；`set_capture_engaged()` 只续接已启动的动画。每轮保留原始 7 帧、7 帧/秒，继续处理目标时逐轮播放，期间的新吸入合并为下一轮，不重置当前进度；停止后播完收尾并恢复第 1 帧。隐藏、切工具、失焦及重开清掉状态。捕网帧由投出/收拢进度驱动；独立预览保持原始 7／5 帧每秒。捕网源目录标注为「旧网」，没有收网与携带序列，玩法中的收拢使用展开原画缩放。角色外观本次保留原样，黏液怪移动仅供独立预览。

## 花朵占领地壳的近景概念（2026-10-10）

独立入口为 `features/territory_preview/flower_claim_preview.tscn`。进入后自动播放一轮 7.8 秒的「花出现 → 连片蔓延 → 稍作停留 → 下沿挂滴、拉长、脱落」；空格或点击花朵重播，C 切换原色，R 随机更换形状与大小，H 隐藏／恢复操作栏，Esc 返回主菜单。上方操作栏可切换双花／单花、分别调整两块大小、拖动完整过程进度，以及切换「蓝盖粉／粉盖蓝」。本轮只交付画面预览，未接入正式治理和经济状态。

先用内置 imagegen 基于现有近景截图与史莱姆花原画生成 `assets/territory_preview/flower_claim_concept.png`，完整提示词保存在同目录 `.prompt.txt`。Godot 使用原有星球六帧动画、背景和花朵场景实时还原，未将概念图作为运行背景。取景沿用近景半径、地平线及水平偏移，单独旋转到原画中较完整的一块浅色岩层，便于比较染色。

本版以用户提供的 `assets/territory_preview/flat_flow_reference.png` 为造型参考，只取其地块色面与大弯轮廓，忽略右侧巢穴。复用场景为 `scenes/effects/claimed_crust.tscn`，检查器可调两种颜色、染色强度、各自大小与源点、形状种子、覆盖顺序、蔓延和挂滴进度；材质每个实例独立。`paint_flow_field.gd` 用平滑连片与侧面凹口组织轮廓，去掉离散喷点；根据地壳纹理和低频局部阻力预计算到达时间，保留分段推进的节奏。轮廓距离与到达时间分开存入纹理，避免完成后的边缘呈格子锯齿。更换大小或形状才重建到达图，播放只更新材质进度。

颜色按用户指定的 Splatoon 式覆盖关系展示：后涂的颜色直接替换先涂的颜色，交叠处不混成第三种颜色。材质改为平面色面与轻微印刷颗粒，去掉原岩层明暗调制、边缘高光、厚边阴影和光泽条纹；完整覆盖区与只显示上层颜色时相同，仅边缘作抗锯齿过渡。遮罩固定在贴图坐标内，保留原图透明处。

滴落出口从色块实际下沿计算：检查向下突出的局部最低点，估计其上方相邻色柱的颜料量，并排除过近的出口；小块可只有一个，大块最多三个。较大积料对应更宽、更长的挂滴。所有蔓延完成后才开始挂滴，出口之间略微错开，经历积料、拉长、收颈、脱落并留下短痕；一轮结束后停住，不无限重复。它是可重复的二维表现规则，不是体积流体模拟。双花默认约 4.91 秒完成铺色，5.46 秒后进入挂滴阶段；这些数值由本预览自行选定。预览脚本拥有过程进度，不写入正式玩法数据。

- [Terra Nil 实机片段画面](https://www.gamestar.de/videos/spielstart-in-terra-nil-von-der-einoede-zum-gruenen-aufbau-paradies,124049.html)：灌溉设备附近的绿地与灰褐土地直接形成范围对比；借鉴土地本身变色与清晰边界，不引入方格地图和建筑。动画时长为本预览自行选定。
- [Valve：Making and Using Non-Standard Textures，GDC 2011](https://steamcdn-a.akamaihd.net/apps/valve/2011/gdc_2011_grimes_nonstandard_textures.pdf)：其《Portal 2》水面部分通过可编辑流向、边界减速和局部积聚组织表现，而非依赖完整流体模拟。本版借鉴“流向／积聚分开控制”的思路；二维颜料的出口筛选与挂滴时序为本项目自定，不声称复现该游戏的颜料滴落实现。
