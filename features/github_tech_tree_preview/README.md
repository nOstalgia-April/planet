# 交互科技树预览

打开 `github_tech_tree_preview.tscn` 按 F6。该入口与正式游戏、主菜单科技树预览、科技调参工具共用 `scenes/ui/interactive_technology_page.tscn`。

当前采用用户确认的版式2素材；悬停查看说明，直接点击节点购买。未解锁节点显示灰锁；已显露节点显示等级／上限与糖果费用，价格数字按是否买得起区分颜色。拖动节点、右键平移和滚轮缩放保留，再次进入沿用上次缩放；右侧详情栏与左下角缩放／恢复布局控件已移除。

当前素材来源、交互说明和检查入口见 [科技树说明](../technology_tree_preview/README.md)。
