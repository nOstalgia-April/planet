# 科技树背景四版对照

打开 `technology_screen_studies.tscn`，按 F6。下拉框或数字 1–4 切换四版，0 对照当前正式背景；鼠标移动可试局部扰动。研究、拖动、平移、缩放沿用正式科技树；试买只影响本次预览，不保存进度。

## 本次范围

沿用正式 `disk_demo.tscn` 和共用科技树，不替换布局、节点、图标、文字、详情栏、颜色状态或连线。四版只在预览实例中替换背景 shader，正式游戏仍使用用户已确认的当前版本。此前生成的整页重设计概念图不作为本次方案。

所有版本保持暗红黑底、竖线与两处水平波带，密度 96、波幅 0.032、速度 0.36；四边粉光宽度 0.055，强度 0.32。CRT 只作用于背景，不处理文字或节点。

| 版本 | 画面变化 | 与故事的联系 |
| --- | --- | --- |
| 1 舱内显像 | 轻微不规则墨迹、细线磷光，边缘更柔和而不收窄 | 像开场飞船内手绘、胶质的荧屏；最接近当前版本 |
| 2 色素输送 | 少量原有竖线中浮动粉色色素短段，极少量低饱和薄荷色 | 呼应飞船取得颜色与吸管输送；不增加新的线路 |
| 3 胶膜感应 | 原双波带略有弹性，鼠标附近推开线纹并带微弱粉色表面反光 | 让屏幕像史莱姆文明培育出的软胶介质 |
| 4 取色余波 | 两道波带交错积聚微弱暖粉色，再留下短暂余光 | 呼应开场取色补能，仅作环境表现，不表示新资源或玩法状态 |

建议优先看第 3 版的鼠标感受；若希望最小改动，选第 1 版。第 2、4 版偏重“取色”叙事，需在动态画面中比较。

## 设计依据

开场 P1–P7 的画面顺序是灰色飞船航行、仪表减少、发现并靠近彩色星球、飞船获得颜色、星球变灰。把它解读为取色／补能是视觉推断，动画没有文字明确说明动机。玩法循环是吸取／捕网采集怪物取得糖果，投入全局研究与逐巢建设，最终让现存巢穴全部自动化并持续产糖。

画面风格取自开场原帧、当前星球背景及粉色史莱姆：粗而不规整的手绘轮廓、喷笔／蜡笔颗粒、果冻软体，亮生物与暗红黑／灰地表形成对比。用户给定技能树参考仅延用背景纹理和宽而弱的四边光，不引入其布局或新连线。

## 验证与调节

四个 shader 的常用参数可直接在 Inspector 调整；`effect_time=-1` 为正常动画，非负值可固定时间便于对比。预览通过同一个材质实例切换 shader，保留正式鼠标响应脚本。

`-- --capture` 输出 1280×800、1920×1080 及鼠标扰动截图到 `artifacts/technology_study_*.png`，并核对各版节点坐标和连线一致。使用 Godot Movie Maker 的 24 FPS 模式配合 `-- --movie` 可输出四版各 5 秒的固定鼠标轨迹对照。
