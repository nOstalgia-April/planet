# 物品动画预览

标题页点击「预览 → 物件与巢穴」即可查看全部十二个物件场景。在 Godot 中也可以打开本目录的 `物品动画总览.tscn`，按 **F6**，或直接运行任一 `…预览.tscn`，从对应物件开始查看。右上角可返回主菜单。

三种巢穴的升级和产怪动画按 **12 帧/秒** 播放，其他物件保持 **8 帧/秒**。底部显示当前物件帧率，可以切换物件和动作、暂停、重播、逐帧查看、拖动帧进度，以及开关循环。空格暂停/继续，R 重播，左右方向键逐帧查看。单次动画在预览中循环时，末帧默认停留 0.75 秒，可在预览根节点的 `replay_delay` 中调整。

## 编辑与复用

每个物件都是以接地点为原点的 `Node2D`，包含“画面/贴图”和“动画播放器”。可在 Godot 的 AnimationPlayer 时间轴中直接修改贴图帧、位置和比例；巢穴时间轴步长为 1/12 秒，其他物件为 0.125 秒；根节点的 `frames_per_second` 与时间轴帧率保持一致。放大物件时调整“画面”或物件根节点的比例，避免覆盖由动画控制的“贴图”位置和比例。

场景使用最近邻过滤。史莱姆跳跃第 004–007 帧补偿原画布的横向跳变；黏液花产出缩放为 0.225，地鼠夹夹缩放为 0.55；巢穴跨序列校准比例和接地点。这些调整只存在于场景轨道，图片文件保持原样。不同动作间的最终美术尺寸仍可以继续在时间轴中微调。

`res://scripts/物品动画/动画物件.gd` 提供 `play_clip(动作名)`、`show_frame(动作名, 从0开始的帧号)`、`get_frame_count(动作名)` 和 `clip_finished(动作名)` 信号。正式实例不自动播放；由所属对象主动调用。待机自身循环，升级和其他动作单次结束后保留末帧。预览使用独立的动画副本与重播计时，因此循环开关不会改写其他实例的动画设置。

这些独立物件只负责表现，不结算产出、巢穴等级或怪物行为。主玩法现由 `scenes/world/nest_art.tscn` 组合史莱姆／黏液巢穴与花朵：模型等级 0／1／2／3 对应原画阶段 1／2／3／4，升级逐段播放，自动化后进入花朵待机，真实自动采集触发产出。巢穴的来源标识、存量、怪物生态与收入规则仍由原模型维护；花的动画不自行发放糖果。黏液 3→4 接入时跳过重复前五帧，与完整演出一致。地鼠尚无玩法物种，本次保留独立预览；史莱姆角色未替换。

真实产怪信号通过 `NestView.pulse_spawn()` 触发对应物种、等级的产怪动作，主菜单 start、近／远景游玩预览与基础 Demo 共用。单批多只怪物不反复重播首帧，结束后恢复当前等级外观；升级优先，升级期间的产怪反馈合并为一次，升级完成后播放。进入自动化花朵、重置或切换物种会清理旧产怪动作。动画不延迟生成、不改变产怪数或间隔。防重叠间距包含新增伸展帧，当前星球自动计算为 10 处位置。
