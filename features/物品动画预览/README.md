# 物品动画预览

在 Godot 中打开本目录的 `物品动画总览.tscn`，按 **F6**。也可以直接运行任一 `…预览.tscn`，从对应物件开始查看。主游戏入口保持原有配置。

所有动画按 **8 帧/秒** 播放。底部可以切换物件和动作、暂停、重播、逐帧查看、拖动帧进度，以及开关循环。空格暂停/继续，R 重播，左右方向键逐帧查看。单次动画在预览中循环时，末帧默认停留 0.75 秒，可在预览根节点的 `replay_delay` 中调整。

## 素材与命名

203 张原始 PNG 已复制至 `res://assets/物品动画/`，按“物件/动作/001.png”组织。文件与来源逐个 SHA256 核对；没有重绘、裁切、重采样或删除重复帧。中文名称统一使用“黏液”，原“史莱姆产金币”归入“史莱姆花/产出”。全部原文件到新路径的映射、校准说明见 `res://assets/物品动画/来源与命名.json`。

“地鼠/地下前进”和“地鼠/鼓包”的画面逐帧相同；“地鼠/跳水”和“地鼠/钻地”也相同。两对原图都保留，场景分别使用鼓包、钻地资源。“看板娘/静态图”保留三张立绘，不作为连续动画。

## 编辑与复用

每个物件都是以接地点为原点的 `Node2D`，包含“画面/贴图”和“动画播放器”。可在 Godot 的 AnimationPlayer 时间轴中直接修改贴图帧、位置和比例；时间轴步长为 0.125 秒。放大物件时调整“画面”或物件根节点的比例，避免覆盖由动画控制的“贴图”位置和比例。

场景使用最近邻过滤。史莱姆跳跃第 004–007 帧补偿原画布的横向跳变；黏液花产出缩放为 0.225，地鼠夹夹缩放为 0.55；巢穴跨序列校准比例和接地点。这些调整只存在于场景轨道，图片文件保持原样。不同动作间的最终美术尺寸仍可以继续在时间轴中微调。

`res://scripts/物品动画/动画物件.gd` 提供 `play_clip(动作名)`、`show_frame(动作名, 从0开始的帧号)`、`get_frame_count(动作名)` 和 `clip_finished(动作名)` 信号。正式实例不自动播放；由所属对象主动调用。待机自身循环，升级和其他动作单次结束后保留末帧。预览使用独立的动画副本与重播计时，因此循环开关不会改写其他实例的动画设置。

这里只提供表现和预览，不结算产出、巢穴等级或怪物行为。花的“产出”动作不自行发放金币/糖果。巢穴变花的演出与现版 Demo 保留巢穴及实体生态的接入关系，留到正式玩法接入时处理。
