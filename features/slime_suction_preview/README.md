# 粉色史莱姆吸取预览

在 Godot 中打开 `res://features/slime_suction_preview/slime_suction_preview.tscn`，按 F6 运行。

- **吸力预览**：持续展示附近小怪的偏移、倾斜和轻微拉伸，再次点击恢复。
- **吸取一次**：播放从原状到拉长、向吸口移动、消失的过程，短暂停顿后自动复位。
- **慢放**：默认开启，以四分之一速度查看；关闭后使用 Demo 的基础处理时间 0.6 秒。
- 在小怪附近按住鼠标左键，可以自行移动吸口测试；移出内圈时只有外围吸力表现。
- 中途松手或移远时，贴图平滑恢复并回到原位，方便重复比较。
- 点击 **复位** 或按 R 重新测试。

素材直接引用 `assets/globe_preview/monster_cutout.png`，没有改动原图。该图来自 Notion 策划案草图 02 的粉色双触角小怪；来源记录沿用 `assets/globe_preview/README.md`。

本场景测试单张贴图整体变形：身体、五官、触角、尾巴与描边一起缩放。吸取的宽度压缩 0.37、高度伸长 0.60，外围吸力的横向 0.95、纵向 1.12，以及偏移、倾斜、平滑恢复沿用圆盘 Demo 的表现参数。它不包含分层五官或局部网格变形。

吸口和范围圈放在小怪后面，避免遮住五官。中途松手后回到原位、完成后自动复位是本预览的重复观察功能，不用于改变圆盘玩法规则。

`pink_slime_view.tscn` 将贴图、变形节点和接地影分开；在其根节点检查器可以调整贴图、显示高度、宽度压缩、高度伸长，并在编辑器里设置吸取进度或外围吸力强度预览。测试场景根节点可调吸取时间、慢放倍率和预览放大倍数。放大仅用于观察贴图，不改变主玩法参数。

这是独立美术小样，没有接入圆盘玩法的收益、怪物生成或球面预览，也没有改变项目主场景。
