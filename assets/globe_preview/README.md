# 草案怪物预览素材

默认素材：`monster_cutout.png`，RGBA 透明 PNG。

来源：[Notion《基础策划案 v0.2》](https://app.notion.com/p/3ecab9cff76081c2a0e9f837df169e17) 第 6.1 节「造型草图 02」左下角的粉色双触角小怪。

通过内置 `image_gen` 图像编辑工具制作透明提取图，保留粉色身体、双触角、右侧尾巴、黑色手绘轮廓与身体高光。原始草图和提取记录保留在本机 `source/`，不随公开源码仓库上传。此图用于当前视角小样，不代表正式美术定稿。

场景在加载时按透明轮廓确定显示范围和脚底位置，不要求导入的图片先裁成紧边。

构图参考：Notion 第 6.2 节已有的 A Planet of Mine 截图，本机参考原图不随公开源码仓库上传。采用圆形世界作为主画面、地表物件建立空间关系；控制区仅保留本预览需要的旋转提示、数量、导入和复位。

`source/` 已设置 `.gdignore`，原始参考图片不会作为游戏资源导入。
