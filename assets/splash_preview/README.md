# 中央喷溅素材

`source_concept.png` 是本次用户提供的概念图原文件副本，尺寸 486 × 1083。

预览默认在 shader 中裁取第二幅图的中央粉色喷溅，原始有效像素范围为 x=205…249、y=428…471（45 × 44）。根据粉色与黑色背景的通道差异生成透明度，保留原图轮廓。`splash_canvas.svg` 仅为 shader 提供方形绘制范围，不代替喷溅造型。

`central_splash.png` 是用内置 imagegen 对同一对象作透明提取与放大重建的备用素材（1448 × 1086，含 alpha）。重建版与原图轮廓存在细微差异，默认预览不使用它。低分辨率原图放大后会保留原始像素边缘，后续正式美术可沿该轮廓提供高清透明素材。

生成方式：内置 imagegen，background-extraction，transparent_background=true。提示词：只提取第二幅红色背景图里星球中央的粉色喷溅和左侧小液滴，移除星球、背景、气泡与文字，保持方向、比例及不对称轮廓，放大居中、透明留白，不加渐变、阴影或发光。

central_splash_original.png 是引擎直接裁取原图、抠背景后导出的透明 PNG，66 × 64，包含周围留白。它保留原始低分辨率轮廓，区别于上面的放大重建备选。
