# 小粉脚底阴影

来源：用户 2026-10-13 提供的「小粉阴影/小粉阴影/未命名作品-1.png」。`原始阴影.png` 为未改写的原文件；「参考.png」用于校准灰度、脚底位置和宽度，不作为运行贴图。

原图带不透明白底。`shaders/pink_ground_shadow.gdshader` 在显示时从白底恢复边缘覆盖率，再以正片叠底压暗地面，白底不产生颜色，避免固定灰色在深色地面上反而发亮；`scenes/effects/pink_ground_shadow.tscn` 截取椭圆区域，按原角色坐标设置为约 82×19、中心略高于脚底，强度 0.58，在白底上与参考图灰度相符。可在此场景的 Ink 节点调整位置、缩放及 self_modulate 透明度。

正式接入为 `scenes/world/slime.tscn` 中 Art 前面的 GroundShadow。角色尺寸、巨型倍率、显示下沉及星球投影补偿同步；跳跃时缩小、淡化，吸取和抛落时隐藏，回到地面恢复。不参与角色捕获边界，也不套用金色身体材质。
