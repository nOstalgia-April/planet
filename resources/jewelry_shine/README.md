# 高价值个体的金饰掠光

三个高价值动画场景分别挂载 `scenes/effects/jewelry_shine.tscn`。每个实例持有独立随机数发生器、计时和材质；金饰遮罩及帧配置共享。普通个体没有启用的扫光。

- 首次出现随机等待 0.5–3 秒；每次扫光 0.6 秒，结束后冷却 2 秒，再随机等待 0.5–3 秒。
- 白光从饰品左下掠向右上，只改变金属区域，保留角色身体、宝石、绒面和黑色描边。角色原有的颜色调制与透明度仍有效。
- 根据 Sprite2D 的贴图变化同步遮罩，涵盖待机、跳跃、夹夹、钻地与吸入；纯土堆没有遮罩。隐藏或进入无饰品帧会取消当前扫光并暂停计时，重新可见后继续等待；游戏暂停和局部速度为零时冻结计时。
- 待机效果沿用 2026-10-17 已确认的预览。33 张裁剪遮罩对应 40 张原动画图中实际露出饰品的帧，原图与动画轨道不改动。

原始饰品图层保存在 `assets/effects/jewelry_shine/source_layers/`，来自用户提供的金项链与两顶皇冠。用 `python tools/build_jewelry_shine_masks.py` 重建遮罩与三个 `.tres`；需要 Pillow、NumPy、SciPy。运行时只引用导入资源，不读取微信目录或临时产物。

`tests/jewelry_shine_check.tscn` 检查六只个体的计时、暂停和逐帧绑定。`tests/jewelry_shine_visual_check.tscn` 在当前近景游戏中显示每种两只个体，一只扫光、一只等待；传入 `-- --capture <绝对PNG路径>` 才保存截图。编辑器内 F6 运行 `features/物品动画预览/高价值饰品掠光预览.tscn`，可切换三个高价值个体及其完整动画。
